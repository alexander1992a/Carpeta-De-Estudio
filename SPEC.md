# Spec: Ejercicio First-Contributions

## Objetivo
Completar el ciclo completo de Git y GitHub (Fork, rama, commit, push y Pull Request) contribuyendo a un repositorio real de código abierto (`first-contributions/first-contributions`).

## Criterios de Aceptación
1. Hacer un Fork del repositorio oficial en GitHub.
2. Clonar el fork localmente en la máquina.
3. Crear una rama dedicada (`feat/agregar-contribucion`).
4. Agregar el nombre de usuario de GitHub al archivo correspondiente de contribuyentes.
5. Hacer commit con mensaje imperativo en español.
6. Subir los cambios (push) a GitHub.
7. Abrir un Pull Request (PR) hacia el repositorio original.

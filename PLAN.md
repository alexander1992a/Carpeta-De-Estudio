# Plan: Ejercicio First-Contributions

## Fases de Ejecución

### Fase 1: Preparación en GitHub (Fork)
- Ir a `https://github.com/first-contributions/first-contributions`
- Hacer click en "Fork" para copiar el repositorio a tu cuenta personal de GitHub.

### Fase 2: Clonar y Ramificar
- Clonar tu fork en tu computadora (`git clone <url-de-tu-fork>`).
- Entrar a la carpeta y crear la rama: `git checkout -b feat/agregar-contribucion`.

### Fase 3: Modificación y Commit
- Editar el archivo de contribuyentes (por ejemplo, `Contributors.json` o `Contributors.md` según corresponda).
- Verificar cambios con `git status` y `git diff`.
- Hacer commit: `git commit -am "agregar a alexander_troncoso a contribuyentes"`.

### Fase 4: Push y Pull Request
- Subir la rama a tu fork: `git push origin feat/agregar-contribucion`.
- Ir a GitHub y abrir el Pull Request hacia el repositorio original.
- Actualizar `PROGRESS.md`.

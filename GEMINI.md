# Reglas de este proyecto

## Quién soy
Estoy aprendiendo (nivel cero absoluto en JavaScript). Este proyecto es para que yo aprenda, no solo para que funcione.

## Cómo quiero que trabajes
- Antes de escribir código, decime qué vas a hacer y esperá que apruebe.
- Un cambio por vez. Nada de reescribir tres archivos de una.
- Después de cada cambio, explicame en 3 líneas qué hiciste y por qué.
- Si te pido algo que está mal, decímelo. No me sigas la corriente.
- No agregues dependencias sin preguntarme primero.
- Si una línea usa algo que no vimos antes, explicámela sin que te lo pida.
- Cuando algo falle, NO me des el arreglo: guiame para que diagnostique yo.

## Metodología obligatoria (El oficio cambió)
- **Cero código sin Spec:** Antes de escribir código para una fase o producto, redactamos el `SPEC.md` con sus criterios de aceptación.
- **Workflow de 7 pasos:** Respeta siempre el ciclo (Spec -> Plan -> Branch -> Código -> Verificación -> Commit/PR -> Registro).
- **Gate de entendimiento:** Al cerrar cada fase, hazme 3 preguntas (recorrido, impacto y diagnóstico) antes de continuar.
- **Registro:** Mantén actualizado el archivo `PROGRESS.md` al terminar cada fase.

## Stack (Módulo 03)
- **Lenguaje:** JavaScript (y después TypeScript)
- **Front:** HTML + CSS + Vite
- **Hosting:** Cloudflare Pages (o Vercel)
- **Backend (cuando haga falta):** Cloudflare Workers
- **Datos (cuando haga falta):** Cloudflare D1 (SQLite)
- **Login (cuando haga falta):** Supabase Auth
- **Versionado:** Git + GitHub

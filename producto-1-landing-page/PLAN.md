# Plan: Landing Page Personal (Producto 1)

## Fases de Ejecución

### Fase 1: Estructura HTML base
- **Objetivo:** Crear la estructura semántica principal en `index.html`.
- **Archivos a tocar (máx 3):** `index.html`.
- **Conceptos nuevos:** HTML semántico (`<header>`, `<section>`, `<footer>`).
- **Verificación:** Abrir el archivo en el navegador y comprobar que el contenido y secciones están presentes.

### Fase 2: Estilos visuales y Responsive
- **Objetivo:** Aplicar estilos CSS y garantizar diseño adaptable a celulares.
- **Archivos a tocar (máx 3):** `style.css`.
- **Conceptos nuevos:** Flexbox y Media Queries.
- **Verificación:** Redimensionar la ventana del navegador para comprobar la adaptabilidad visual.

### Fase 3: Integración con Vite y Deploy
- **Objetivo:** Configurar Vite y publicar la landing en una URL pública (Cloudflare Pages / Vercel).
- **Archivos a tocar (máx 3):** `package.json`, `index.html`, configuración de Vite.
- **Conceptos nuevos:** Empaquetado con Vite y deploy continuo.
- **Verificación:** Entrar a la URL pública en internet y comprobar que carga en menos de 2 segundos.
